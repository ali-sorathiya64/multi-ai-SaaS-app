# 🚀 AI Content Creation Platform

An AI-powered full-stack web application that helps users generate high-quality content using modern AI models. The platform includes article generation, blog title generation, AI image generation, image editing, PDF summarization, and user subscription management.

The project is divided into two repositories:

* **Frontend** – React + Vite + Tailwind CSS
* **Backend** – Node.js + Express + PostgreSQL + Gemini AI + Docker

---

## ✨ Features

* 📝 AI Article Generator
* ✍️ AI Blog Title Generator
* 🎨 AI Image Generator
* 🖼️ AI Background Removal
* 🧹 AI Object Removal
* 📄 PDF Document Summarizer
* 🔐 Secure Authentication with Clerk
* 👤 User Dashboard
* 📚 Creation History
